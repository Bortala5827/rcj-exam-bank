# RCJ Training · 职业能力训练系统（MVP 2.0）

> 不是"体测工具"，而是"职业能力训练系统"。
> 核心：**标准不是资产，成长数据才是。** 把运动科学翻译成用户能执行的东西，而不是堆教材。

## 设计原则
- **标准全由用户自定义**：平台一个官方数字都不背 → 零误导风险，永不因标准变化失效。
- **能力地图**：像游戏属性一样（心肺/力量/爆发/速度/灵敏/恢复），用户感觉"在升级能力，不是刷数字"。
- **成长记录属于用户**：数据存本机，不会因标准变化失效；未来极易接入线下体培 / 学员训练档案。
- **不竞争 Keep、不竞争公告查询站**：RCJ 的价值是"帮备考/入职人群记录成长过程"。
- **与 SoloSpeak 同哲学**：用户自己的声音属于用户 / 用户自己的成长数据属于用户；记录成长，不制造焦虑。

## MVP 四个模块
| 模块 | 作用 |
| :--- | :--- |
| ① 我的目标 | 先选"我要成为谁"（深圳辅警/消防员/入伍/综合体能提升）→ 自动生成**目标画像**（六维能力侧重）+ 用户自定义目标项（项目名+目标值，数值留空由用户填当地公告） |
| ② 我的测试 | 按日期记录各项目实测值，存本机 |
| ③ 成长记录 | **能力地图**（六维进度条）+ 逐项时间线对比、距目标差距、趋势 sparkline |
| ④ 为什么练 | 运动生理学知识卡片（已核实文献）：有氧基础(Zone2)/间歇与速度/力量与爆发/恢复与防伤/热身/周期化 |

> 参考模板为"非官方示例"，仅给项目名，数值一律由用户填当地公告。知识卡片附真实文献延伸阅读（Zone2 专家共识 Int J Sports Physiol Perform 2025；间歇训练生理学教学指南 Advances in Physiology Education 2025）。

## 技术
- 纯前端单页 + `localStorage`，无后端、无网络请求。
- 时间类值内部存秒（`4:25`→265），显示再格式化回 `m:ss`。
- 能力进度 = 首次实测→最新实测 相对目标的改善比例（clamp 0–100%）。
- 手机优先，底部 tab 导航，RCJ 风格（品牌蓝 + 暖色信号 + 干净卡片）。
- 已支持：**导出训练档案 JSON**（跨设备备份、线下学员档案迁移）。
