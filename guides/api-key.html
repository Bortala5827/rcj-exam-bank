国内大模型免费 API 获取教程

很多刷题站、学习类小工具（比如各类真题刷题站的 AI 点评、语音转写功能）都会用到国内大模型的 API。本篇手把手教你免费申请自己的 API Key，并以 DeepSeek 和 硅基流动 SiliconFlow 为例给出完整步骤。Key 只存在你自己浏览器的本地存储，不上传任何人，放心填。

一、为什么需要 API Key

这类工具是「前端 + 你自己的 Key」模式：代码跑在你浏览器里，调用大模型时带你的 Key，费用走你自己的额度。Key 和对话内容只存你本机，不上传。

二、两种用途

  • 🤖 AI 点评 / 对话：OpenAI 兼容接口，DeepSeek、硅基流动、Kimi、智谱等都行。
  • ☁️ 语音转写（ASR）：需要语音识别接口，最稳的是硅基流动 FunAudioLLM/SenseVoiceSmall。纯对话模型不能转写。
💡

省事方案：硅基流动一个 Key 搞定转写+点评。

四、通用拿 Key 步骤

每个平台流程都差不多，掌握一套就能通吃：

  1. 注册 / 登录

    打开官网，用手机号注册或登录（部分支持微信 / 邮箱）。

  2. 找到「API 密钥」入口

    在左侧菜单找 API 密钥 / API Key / 访问控制 / 令牌 / 鉴权。

  3. 创建并复制 Key

    点「创建密钥 / 新建 Key」，生成后立刻复制保存（通常只显示一次，形如 sk-xxxx）。

  4. 确认免费额度

    查看「免费额度 / 体验额度 / 资源包」：新用户一般送几元到几十元，或某些模型直接免费档。

  5. 填进对应工具

    回到工具的 ⚙️ 设置，把 Key + 模型名 + Base URL 填进去，点保存。

五、硅基流动 SiliconFlow

同时支持语音转写和对话，一个 Key 覆盖大多数需求，新手首推。

  1. 注册

    访问 cloud.siliconflow.cn，手机号注册，新用户送体验额度。

  2. 创建 Key

    左侧菜单 API 密钥 → 新建密钥，起名后生成，立刻复制（只显示一次）。

  3. 记下参数

    Base URL：https://api.siliconflow.cn/v1；转写 FunAudioLLM/SenseVoiceSmall，点评 deepseek-ai/DeepSeek-V4-Flash。

六、DeepSeek

高质量对话/推理，支持多模态看图。不支持语音转写，转写走硅基流动。

  1. 注册

    访问 platform.deepseek.com，手机号注册送体验额度。

  2. 创建 Key

    左侧 API keys → Create API key，生成后立刻复制。

  3. 记下参数

    Base URL：https://api.deepseek.com/v1；模型 deepseek-v4-flash（日常）/ deepseek-v4-pro（强推理）/ deepseek-v4-flash-vision-exp（多模态看图）。旧模型名 deepseek-chat 已停用。

七、在工具里怎么填

核心三项：Base URL + Key + 模型名。

① 只做 AI 点评（DeepSeek）

API Base URL：https://api.deepseek.com/v1 API Key：你的 DeepSeek Key 模型名：deepseek-v4-flash

② 点评 + 语音转写（硅基流动，一个 Key 全包）

【AI 点评】Base：https://api.siliconflow.cn/v1 · 模型：deepseek-ai/DeepSeek-V4-Flash 【语音转写】Base：https://api.siliconflow.cn/v1 · 模型：FunAudioLLM/SenseVoiceSmall Key：同一个硅基流动 Key

填完点「🧪 测试连接」验证。适用站点：深圳辅警、惠州辅警、SoloSpeak。

八、常见问题

  • 401 / Key 无效：复制时带进了空格，或额度用完。重新复制完整 Key。
  • 404：接口地址拼错，多/少了 /v1。对照上表核对。
  • 担心 Key 泄露：Key 仅存你浏览器。如担心，去平台「删除密钥」即可，旧 Key 立刻失效。
