Cloudflare 注册与 Pages 部署

Cloudflare Pages 能免费把你放在 GitHub 上的静态网站部署成全球可访问的网址，还自带 CDN 加速。本篇手把手带你从注册到上线。

本篇目录
  1. 注册 Cloudflare 账号
  2. 前置：准备代码仓库
  3. 创建 Pages 项目
  4. 配置构建（静态站）
  5. 部署与自定义域名
  6. 之后如何更新

一、注册 Cloudflare 账号

  1. 打开官网

    访问 cloudflare.com，点右上角 "Sign up"（注册）。

  2. 用邮箱注册

    填邮箱 + 设置密码，免费版足够个人使用，无需绑卡。

  3. 验证邮箱

    查收验证邮件并点击确认，登录后台（Dashboard）。

二、前置：准备代码仓库

Pages 的工作方式是"从 GitHub 拉代码自动部署"，所以它不会直接收你的文件，你需要先把网站文件存到 GitHub。请先完成：

  • GitHub 注册与仓库管理：建一个仓库，把 index.html 传上去。
📌

仓库里至少要有一个 index.html 作为首页，否则部署后打开是空白。

三、创建 Pages 项目

  1. 进入 Pages

    在 Cloudflare 后台左侧菜单找到 Workers & Pages → 点 Create → 选 Pages 标签页。

  2. 连接 Git

    点 Connect to Git，授权 Cloudflare 访问你的 GitHub，然后选中刚才建好的仓库。

  3. 首次授权

    按提示在 GitHub 弹窗里点 "Authorize Cloudflare"，允许它读取你的仓库。

四、配置构建（静态站重点）

这是最容易配错的一步。纯静态站点（HTML/CSS/JS，不需要 npm 构建）按下面填：

  • Framework preset：选 None（无框架）。
  • Build command：留空（不用敲任何命令）。
  • Build output directory：首页在仓库根目录就填 /；若放在子目录（如 docs/）就填对应目录名。
⚠️

不要随手选了某个框架（如 React/Vite），否则它会去跑 npm build，找不到配置就会部署失败。纯 HTML 站一律选 None。

五、部署与自定义域名

  1. 开始部署

    点 Save and Deploy，等 1–2 分钟，状态变绿即成功。

  2. 拿到网址

    你会得到一个 xxx.pages.dev 的免费子域名，别人点开就能访问。

  3. （可选）绑定自己的域名

    在 Pages 项目里点 Custom domains → 添加你的域名，按提示去域名商后台加一条 CNAME 解析即可。

💡

没有域名也能用 .pages.dev 免费跑；想用自己域名再 later 加，不影响已上线内容。

六、之后如何更新

部署是一次性的，更新是自动的：

  • 你只要在 GitHub 里改文件并 提交（Commit/Push），Cloudflare 会自动重新部署。
  • 改完去 Pages 项目的 Deployments 看最新一条是否变绿。
  • 浏览器看旧版？按 Ctrl+F5（Mac：Cmd+Shift+R）强制刷新。
🚫

Cloudflare Pages 免费版对单个文件有 25MB 上限。上传前请确认没有超大 PDF/视频，否则整次部署会失败。
