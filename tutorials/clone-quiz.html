零成本复制你的刷题站

本篇把前面三课串起来：把你的题目整理成数据，生成可在线刷题的网页，再免费部署上线。整套下来成本为 0，适合做备考资料站、知识库、个人作品集。

本篇目录

  2. 第一步：整理你的题库
  3. 第二步：生成刷题网页
  4. 第三步：免费部署上线
  5. 第四步：分享与合规提醒

一、这套方案在做什么

核心思路就三步：数据（题目）→ 模板（网页）→ 托管（免费平台）。你只负责准备题目，网站结构和上线流程都可以复用现成方案，不必从头写代码。

  • 题目用表格/文本存（Excel、CSV、Markdown 都行），和"网站长什么样"解耦。
  • 网页用模板或 AI 生成，负责把题目渲染成"在线答题 / 错题复盘"的界面。
  • 托管用 Cloudflare Pages + GitHub，永久免费、全球可访问。

二、第一步：整理你的题库

先把题目规整成"机器好读"的格式。最简单的做法是建一张表，每行一道题：

题型, 题目, 选项A, 选项B, 选项C, 选项D, 答案, 解析 单选, 下列属于行政处罚的是？, 拘役, 罚款, 管制, 有期徒刑, B, 罚款属行政处罚…… 判断, 辅警可以单独执法。, , , , , 错, 辅警须在民警带领下开展工作。
💡

没有 Excel 也没关系，用记事本按"题目 == 答案"一行一道题的格式写也行；重点是每道题的字段要一致，方便后续导入。

⚠️

注意版权：自己整理的真题解析、原创题目可以放心用；直接搬运他人付费资料再分发，可能侵权，请勿这么做。

三、第二步：生成刷题网页

两条路，任选其一：

路线 A：用 AI 工具生成（零基础推荐）

  1. 把题库给 AI

    按 AI 桌面工具建站 的方法，把上面的题目表粘贴给 WorkBuddy / Trae / Qoder。

  2. 下达指令

    说："请根据这份题库生成一个在线刷题网页，支持单选/判断、提交后显答案、可显示解析，输出单个 index.html。"

  3. 预览微调

    生成后本地打开，用大白话让它改样式、加"错题本"等功能。

路线 B：用现成模板

  • 找开源的静态刷题模板（如 rcj-exam-builder 思路），按其说明把题库填进去。
  • 优势是结构成熟、功能全；劣势是要稍微看懂它的配置方式。

四、第三步：免费部署上线

拿到最终 index.html（和需要的资源）后：

  1. 存到 GitHub

    按 GitHub 教程 建仓库、上传文件。

  2. 连 Cloudflare 部署

    按 Cloudflare 教程 连接仓库、选 None 框架、部署，拿到网址。

  3. 验证

    打开网址，手机和电脑各刷一遍，确认题目能正常显示、答题交互正常。

四、分享与合规提醒

  • 引流思路：免费站点本身可以当"橱窗"吸引访客，再引导到你的完整版/付费服务。
  • 诚实第一：站点展示的能力要真能实现，避免夸大导致信任损耗。
  • 合规底线：不碰他人版权资料、不收集无关隐私、不诱导站外违规交易。
