国内大模型免费 API 获取教程

很多刷题站、学习类小工具（比如各类真题刷题站的 AI 点评、语音转写功能）都会用到国内大模型的 API。本篇手把手教你免费申请自己的 API Key，并以 DeepSeek 和 硅基流动 SiliconFlow 为例给出完整步骤。Key 只存在你自己浏览器的本地存储，不上传任何人，放心填。

⚠️

各平台免费额度会随政策变动，本教程以「怎么免费拿 Key」为主，具体额度 / 可用模型 / 接口地址一律以官网「帮助 / 文档」页为准。

一、为什么需要 API Key

这类工具普遍是「前端 + 你自己的 Key」模式：代码跑在你浏览器里，调用大模型的能力时要带上你申请的 Key，费用也走你自己的额度。这样做的好处是——

  • 数据在你手里：Key 和对话内容只存你本机浏览器（localStorage），不会经过任何中转服务器。
  • 按需消费：免费额度够用时零成本；不够再按需充值，钱花得明白。
  • 一个 Key 多工具通用：只要是 OpenAI 兼容的接口，多数同类工具都能复用同一个 Key。

二、先分清两种用途

工具里用到的接口大致分两类，填的 Key 可以相同也可以不同：

  • 🤖 AI 点评 / 对话（OpenAI 兼容接口）：把「题目 + 你的作答」发给大模型打分或给建议。只要是 OpenAI 兼容的对话接口都能用，DeepSeek、硅基流动、智谱 GLM 等都行。
  • ☁️ 语音转写（ASR）：把录音变成文字。需要支持「语音识别」的接口，目前最稳的是硅基流动 SenseVoice（模型 FunAudioLLM/SenseVoiceSmall）。纯对话模型（如 DeepSeek、智谱 GLM）没有语音识别接口，不能用于转写。
💡

省事方案：直接去 硅基流动（siliconflow.cn） 申请一个 Key，转写和点评都用它。模型分别填 FunAudioLLM/SenseVoiceSmall 和 deepseek-ai/DeepSeek-V3（或 Qwen/Qwen2.5-7B-Instruct 等）。一个 Key 全搞定。

四、通用拿 Key 步骤

每个平台流程都差不多，掌握一套就能通吃：

  1. 注册 / 登录

    打开官网，用手机号注册或登录（部分支持微信 / 邮箱）。

  2. 找到「API 密钥」入口

    在左侧菜单找 API 密钥 / API Key / 访问控制 / 令牌 / 鉴权。

  3. 创建并复制 Key

    点「创建密钥 / 新建 Key」，生成后立刻复制保存（通常只显示一次，形如 sk-xxxx）。

  4. 确认免费额度

    查看「免费额度 / 体验额度 / 资源包」：新用户一般送几元到几十元，或某些模型直接免费档。

  5. 填进对应工具

    回到工具的 ⚙️ 设置，把 Key + 模型名 + Base URL 填进去，点保存。

五、实操一：硅基流动 SiliconFlow

硅基流动是少数同时支持语音转写和对话的平台，一个 Key 能覆盖大多数同类工具的 AI 需求，新手首推。

  1. 打开官网并注册

    浏览器访问 cloud.siliconflow.cn/i/JXohBRlG，用手机号注册 / 登录。新用户注册即送体验额度。

  2. 进入「API 密钥」

    登录后左侧菜单点 API 密钥 → 新建密钥，给密钥起个名字（如 exam-ai）。

  3. 复制 Key

    生成后点复制，立即保存好（之后不再完整显示）。形如 sk-xxxxxxxx。

  4. 记下接口与模型

    Base URL 用 https://api.siliconflow.cn/v1；转写填 FunAudioLLM/SenseVoiceSmall，点评填 deepseek-ai/DeepSeek-V3 或 Qwen/Qwen2.5-7B-Instruct。

六、实操二：DeepSeek

DeepSeek 主打高质量对话 / 推理，适合只做 AI 点评、不做语音转写的场景，价格也很有竞争力。

  1. 打开官网并注册

    浏览器访问 platform.deepseek.com，用手机号注册 / 登录。注册一般会送体验额度（以页面显示为准）。

  2. 进入「API keys」

    左侧菜单点 API keys → Create API key，起个名字后创建。

  3. 复制 Key

    生成后立刻复制保存（DeepSeek 同样只显示一次，形如 sk-xxxx）。

  4. 记下接口与模型

    Base URL 用 https://api.deepseek.com/v1（也可省略 /v1）；模型填 deepseek-chat（对应 V3）或 deepseek-reasoner（对应 R1 推理模型）。

📋

DeepSeek 是纯对话模型，没有语音识别接口，只适合 AI 点评 / 对话类功能，不能用于录音转写。

九、常见问题

  • 提示 401 / Key 无效：多半是复制时带进了空格，或 Key 已过期 / 额度用完。重新复制完整 Key 再试。
  • 手机打不开 / 转写没反应：优先用☁️云端 API（国内直连），比浏览器内置 / 离线方案兼容性更好，华为 / 微信内置浏览器也支持。
  • 只想点评、不录音：可以在「自定义题」里手动贴文字，再点 AI 点评，不一定要录。
  • 担心 Key 泄露：Key 仅存你自己的浏览器，不要截图发给别人、不要填到不明网站。如担心，去平台「删除 / 重置密钥」即可，旧 Key 立刻失效。
