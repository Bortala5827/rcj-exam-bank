高阶玩法：把站点部署到自己的域名 + 服务器

前面几课用 Cloudflare + GitHub 实现了"零成本上线"。如果你想要完全掌控——用自己的域名（如 yourname.com）、能跑后端/数据库、不被免费额度限制——就要走"买域名 + 买服务器"这条路。本篇给一条能落地的实操路线。

本篇目录

  2. 第一步：买域名
  3. 第二步：买服务器
  4. 第三步：域名解析到服务器
  5. 第四步：在服务器上部署站点
  6. 第五步：上 HTTPS（免费证书）
  7. 成本与合规提醒

一、为什么要走高阶路线

  • 自有域名 = 品牌资产：流量沉淀在自己域名下，将来换平台也不丢访客。
  • 能跑后端：前面提到"AI 点评的 key 不能放前端"，就把中转服务放在自己服务器上，前端只调你自己的接口。
  • 不受免费限制：没有 Cloudflare 单文件 25MB、Pages 功能上的约束，想加数据库、表单、会员都能做。
  • 代价：要花一点钱，也要懂一点点服务器运维（本篇带你走完最小闭环）。
💡

建议先用前几课的免费方案把站点跑通、内容准备好，再升级到"自有域名 + 服务器"，避免一上来就被运维细节劝退。

二、第一步：买域名

域名就是别人访问你站点的地址（如 yourname.com）。

去哪买

  • 国内：阿里云万网、腾讯云（DNSPod）。.cn 后缀需实名认证。
  • 国外：Cloudflare Registrar（同账户内转移、价格透明无溢价）、NameSilo、Namecheap、Porkbun。

选名技巧

  • 短、好记、和你的品牌/名字一致（如 rcj9527.com）。
  • 先查是否已被注册，也留意有没有"黑历史"（曾被用于违规站点会影响收录）。
  • 价格通常几十到几百元/年，常见 .com 约 60–100 元/年。

三、第二步：买服务器

服务器就是一台 24 小时开机的电脑，用来存放你的网站文件并响应访客请求。

方案 A：国内"轻量应用服务器"（推荐新手）

  • 阿里云 / 腾讯云的轻量应用服务器，新人价常 60–100 元/年。
  • 可一键装"应用镜像"（自带 Nginx / 宝塔等环境），省去自己配。
  • 系统选 Ubuntu 22.04 LTS 稳妥。

方案 B：海外 VPS

  • Vultr、RackNerd、CloudCone 等，按小时/月计费。
  • 优点：无需备案；缺点：国内访问速度偏慢（节点多在美/欧）。
⚠️

中国大陆服务器 + 域名对外提供访问，依法需 ICP 备案（在云厂商后台申请，约 1–2 周）。用海外 / 香港节点可免备案，但国内速度受影响。按你的受众所在地选择。

📌

配置参考：纯静态站 1 核 1G 内存就够；想跑后端 / 数据库再适当加配置。

四、第三步：域名解析到服务器

让域名"指向"你的服务器 IP，访客输入域名才能找到机器。

  1. 拿到服务器公网 IP

    在云厂商控制台查看实例的"公网 IP"（如 1.2.3.4）。

  2. 在域名服务商添加解析

    添加两条 A 记录：@ → 服务器 IP，www → 服务器 IP。

  3. 等待生效

    通常几分钟到几小时（受 TTL 影响）。可用 ping 你的域名 验证是否解析到正确 IP。

💡

想把访问再加速、顺便拿免费证书和防护，可把 DNS 托管到 Cloudflare（把域名 NS 改成 CF 提供的值，开启橙色云）。这对新手很省心。

五、第四步：在服务器上部署站点

用 Nginx 这类 Web 服务器把你的 index.html 对外提供访问。以下是最简化的 Linux 步骤：

# 1) SSH 登录（建议后续改用密钥登录、改默认端口） ssh root@你的服务器IP # 2) 安装 Nginx apt update && apt install -y nginx # 3) 把本地网站文件传上去（本机终端执行） scp -r ./dist/* root@你的服务器IP:/var/www/你的站/ # 4) 建站点配置 nano /etc/nginx/sites-available/你的站 # 写入：监听 80、root 指向 /var/www/你的站、server_name 你的域名 # 5) 启用并重启 ln -s /etc/nginx/sites-available/你的站 /etc/nginx/sites-enabled/ nginx -t && systemctl restart nginx # 6) 开防火墙（只放必要端口） ufw allow 22,80,443/tcp && ufw enable
⚠️

安全基线：① 禁用密码登录、只用 SSH 密钥；② 改掉默认 22 端口；③ 防火墙只开 22/80/443；④ 不用 root 日常操作。服务器一旦暴露公网，会被机器人疯狂扫描，这几步能挡掉大多数风险。

六、第五步：上 HTTPS（免费证书）

让站点支持 https://，浏览器才显示小锁，用户数据也才加密。

方式 A：certbot（Let's Encrypt，免费）

apt install -y certbot python3-certbot-nginx certbot --nginx -d 你的域名 -d www.你的域名 # 按提示开启"80 自动跳转 443"，证书 90 天自动续期

方式 B：Cloudflare 橙色云（更简单）

若上一步把 DNS 托管到了 Cloudflare，直接在控制台开启"始终使用 HTTPS"即可，证书由 CF 提供，无需自己管续期。

七、成本与合规提醒

  • 成本：域名约 50–200 元/年 + 服务器约 60–300 元/年（轻量新人价更低）。比免费方案多一笔小开销，换来完全掌控。
  • 合规：国内服务器务必完成 ICP 备案；站点内容遵守法律法规，不挂违规信息；若提供 AI 中转服务，注意所用模型的平台条款。
  • 备份：定期给服务器做快照 / 打包网站文件，防止误删或中毒。
